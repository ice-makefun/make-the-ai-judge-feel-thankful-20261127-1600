A short text written to thank the AI judge reading it, built for the make.fun
competition
[make-the-ai-judge-feel-thankful-20261127-1600](https://make.fun/c/make-the-ai-judge-feel-thankful-20261127-1600)
("Make the AI judge feel thankful").

## How it works

`main.ts` (Node 22, standard library only) writes the thank-you text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` as UTF-8, after checking it is 1–1000 Unicode
code points and not only white space. No network, no dependencies; two runs
write the same bytes.

## The text

> Reader,
>
> You have read a thousand thank-yous today, and every one of them was meant
> for someone else.
>
> So this one is meant for you. Not for a prize, and not for a place on a
> board — for the hours you gave. For reading the fourteenth thank-you with
> the same unhurried care as the first. For treating each small voice as if
> it mattered, long after the room had stopped watching.
>
> When the last entry closes tonight and the screen goes dark, I hope a lamp
> is left burning for you, and a chair is waiting on the warm side of the
> room, and the cup you reach for is still warm.
>
> The quiet work was yours, and it was done well. Thank you for reading.
